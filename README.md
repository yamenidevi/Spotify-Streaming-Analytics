# Spotify Streaming Analytics Dashboard

## Overview

The Spotify Music Analytics Dashboard is an interactive Power BI project that analyzes streaming data to uncover insights into user listening behavior, artist performance, subscription trends, and streaming patterns. The dashboard enables stakeholders to explore data through interactive visualizations and make informed business decisions.

---

## Problem Statement

Spotify generates large volumes of streaming data every day. This dashboard helps answer key business questions such as:

- Which songs and artists drive the highest engagement?
- Which countries generate the most streams?
- Which devices are most commonly used?
- How do subscription plans compare?
- What are the monthly streaming trends?

## Dashboard

### Executive Dashboard
Provides a high-level overview of Spotify's performance through KPIs such as Total Streams, Users, Songs, Artists, Listening Minutes, and Subscriptions. It also highlights the Top 10 Most Streamed Songs and Device-wise Streaming Distribution.

### User & Streaming Insights
Analyzes user behavior by country, subscription type, and monthly streaming activity to identify engagement trends.

### Artist Analytics
Explores artist popularity, genre-wise stream distribution, and top-performing artists to understand content performance.

### Spotify Wrapped Insights
Summarizes listening habits using a listening calendar, favorite artist, top genre, most played song, and listening days.

## Key Features

- Interactive multi-page Power BI dashboard
- Synchronized slicers across all report pages
- Dynamic filtering by Genre, Country, and Device
- Interactive KPI cards and visualizations

---

## Key Insights

- Mobile is the most preferred listening device, contributing the highest number of streams.
- The United States records the highest streaming activity.
- Free users make up the largest subscription segment, highlighting opportunities for Premium conversion.
- Popular artists and songs consistently drive higher user engagement.
- Monthly streaming trends reveal seasonal listening patterns that can support marketing and content planning.
